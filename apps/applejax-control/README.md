# appleJax Control

iPhone companion app for the projectm-tv visualizer. Streams real-time PCM
audio (microphone or local file) over the local network to the tvOS app so
the visualizer can sync to actual audio — bypassing the Apple Music DRM
limitation that blocks tvOS from tapping its own playback.

Built as an Expo CNG app: native code lives in `modules/applejax-audio/`
(Swift, AVAudioEngine + AVAudioConverter). The `ios/` folder is generated by
`npx expo prebuild`.

## Modes

- **Mic** — records the device microphone, captures whatever is playing in
  the room (HomePod, AirPods worn nearby, soundbar, vinyl).
- **File** — picks a local audio file (any AVFoundation-decodable format)
  and streams it while playing it on-device.

## Audio pipeline

```
input format  →  AVAudioConverter  →  22050 Hz mono Float32
              →  1024-sample chunks (~46 ms)
              →  base64 across the JS bridge
              →  TCP framed write
```

## Wire protocol

Each PCM chunk is sent as one TCP frame:

| Bytes | Field           | Notes                                     |
|------:|-----------------|-------------------------------------------|
| 4     | Magic           | ASCII `APJX`                              |
| 4     | Payload length  | `uint32` little-endian, equals `samples * 4` |
| N     | PCM payload     | `Float32` little-endian, mono, 22050 Hz   |

The tvOS receiver listens on a TCP port (default 9999), reads frames,
dewraps the payload, and feeds the floats to
`projectm_pcm_add_float(handle, samples, count, 1)`.

## Run / develop

```bash
npm install
npx expo prebuild --platform ios --clean
npx expo run:ios            # launches on iOS Simulator
# or open ios/applejaxcontrol.xcworkspace in Xcode for device runs
```

## EAS build

```bash
eas build --profile development --platform ios
eas build --profile preview --platform ios
```

`eas.json` defaults are not committed yet — run `eas init` once when ready.
